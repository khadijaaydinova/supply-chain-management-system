# Supply Chain Management System (Java)

A comprehensive simulation of business interactions within a supply chain, developed as part of the Object-Oriented Programming (CS 102) course at Özyeğin University.

## 🚀 Features
- **Business Entities:** Abstract logic for Factories, Markets, and Customers.
- **Production Cycles:** Management of raw materials, product designs, and byproducts.
- **Advanced OOP:** Heavy use of Inheritance, Polymorphism, and Interfaces.
- **Safety:** Robust custom Exception Handling for financial and storage constraints.
- **Reflection:** Dynamic item creation using Java Reflection API.

## 🛠 Tech Stack
- Java 17+
- Stream API
- Custom Exceptions
- Reflection API
