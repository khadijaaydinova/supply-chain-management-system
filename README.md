# Supply Chain Management System (Java)
A comprehensive simulation of business interactions within a supply chain, developed as part of the Object-Oriented Programming (CS 102) course at Özyeğin University.

## Project Overview
This project simulates complex production cycles and the interactions between markets, factories, and customers. The primary focus of the development was on software architecture, clean code principles, and the robust implementation of complex business logic.

## Key Features
**Business Entities:** Abstract logic and behavior modeling for Factories, Markets, and Customers.

**Production Cycles:** Comprehensive management of raw materials, product designs, and manufacturing byproducts.

**Advanced OOP:** Deep implementation of Inheritance, Polymorphism, and Interfaces to create a highly scalable structure.

**Safety & Reliability:** Robust Custom Exception Handling designed to manage financial risks and warehouse storage constraints.

**Dynamic Capabilities:** Utilization of the Java Reflection API for runtime object creation and system element management.

## Tech Stack
**Language:** Java 24+

**GUI:** Java Swing / AWT (utilized strictly for logic visualization and manual testing).

**Core:** Collections Framework (Deque, ArrayDeque), Stream API.

**Advanced:** Reflection API, Custom Exception Handling.

## Functional Interface (GUI)
The application's interface is built using **Java Swing** and **AWT**.

Note: The user interface design is intentionally minimalistic. The primary goal of this project was the implementation and verification of complex backend logic, state management, and real-time event handling. The GUI serves purely as a functional testing tool to monitor and validate the system's underlying business processes.

## How to Run / Testing
To launch the graphical user interface and test the simulation, execute the main method located in the following path:
**src/a_supply_chain_management_system/gui/MainFrame.java**
